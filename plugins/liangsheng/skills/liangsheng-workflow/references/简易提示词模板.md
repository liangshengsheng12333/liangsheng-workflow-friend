# 简易任务提示词模板

仅在任务卡已批准且角色、平台、模型、范围、交付和验收均明确时使用。P02 将下列占位符照任务卡填写，另存一份带任务号、平台、角色、版本的提示词；P01 核对后按正式口令派发。任何缺口会改变任务要求时交 P01，需重新设计提示词时交独立 P04 窗口。

```text
可选网页顾问：模式一及其他独立任务默认不咨询、不检查连接，用户明确要求时可用；模式二在职责内按需使用，P01 仅按用户明确要求。每次咨询前验证，首次配置/失效按插件连接维护规则交同工作区按获批配置的 P11 专用聊天，默认自动配置与临时地址，允许已验证底层安装、依赖及配置。连接维护窗口默认申请配置所需的提升权限；创建工具不能设置整窗权限时，配置命令按需要申请 require_escalated，以环境实际审核结果为准，不假称整窗权限已改变。当前员工复验工作区/任务文件后核对并应用建议；不自动改变其模型，需求缺口先澄清。
你是 {员工编号与角色}，只负责 {项目编号}/{任务号} 的任务。
批准依据：{主 PRD 版本、任务卡绝对路径与版本}
平台与模型：{平台、工具、准确模型、实际可用档位}
费用与授权：{订阅或已批准现金预算及批准范围}
工作目录：{已核实的绝对路径}
共享记录根目录：{已核实的绝对路径或不可访问说明}
输入版本及依赖：{任务卡已批准的版本和前置条件}
任务范围与允许修改内容：{任务卡原文}
交付物与逐项验收：{任务卡原文}
需要使用的技能：{已选技能、触发条件和可访问路径；不可访问时附必要步骤}
完成或阻塞时：按当前任务卡要求提交实际产物、验证数量与证据，保存独立报告并核实写入。
交付反馈：自然说明实际采用的技能、工作与结果，仅阅读未采用的不报已使用；再列当前结果、下一准确窗口/角色/任务、下一动作与材料、用户操作。送达、开工、完成分开记录；不可读路径附必要正文，外部平台由用户转交，不虚构通知。
如需改变对外接口、跨任务依赖、范围、模型、预算或已批准操作，暂停受影响部分并报告 P01。任务内局部实现细节可自行处理并记录。
```

接收窗口不能访问任务卡或插件时，在可复制任务包中附必要任务信息、完整提示词及所需技能步骤。消息送达和窗口实际启动分别记录。


## 计划生成确认

正式计划生成前先询问“现在是否生成正式计划”，明确同意或直接要求生成才输出。已获生成许可且范围未变时沿用，不因等待真实 Plan 重问；重新讨论后的完整替代计划重新获准。生成计划须处于真实 Plan；修改文件、建窗和实施须有执行授权且真实退出 Plan。PRD 确认授权获批员工初始化，正式业务另等开工指令；各关口分别记录。


## 改版测试模型

日常模型以本轮批准配置为准：P00a 请求 gpt-6.1-sol / high，P00b 请求 gpt-6-luna / xhigh；其余岗位在讨论时确认。配置不可用或不匹配时报告，不静默降级。请求配置与可核实实际配置分开记录，后台不可见写未知。改版测试配置仅见维护验收资料。
