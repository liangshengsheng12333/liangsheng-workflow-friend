# 浏览器与咨询

使用当前提供的内置浏览器。提供 `mcp__cua_repl` 时，首次调用严格只做其允许的一个入口（例如 `await cua.createBrowserTab("iab", "https://chatgpt.com/", {visible: true})`），先读返回文档，再用文档支持的 API 与页面实际 DOM。恢复电脑任务时先 `cua.rewriteDocumentation()`。不使用旧 browser-client/Playwright 私有入口，不用 shell/HTTP 冒充网页交互；UI 变化按实际可见页面处理。

## 自动配置网页

保持共享锁覆盖本段。使用 `setup`/doctor 返回的页面 URL、准确连接名和 `mcpUrl`（上游当前提示 `/plugins` 和设置安全页，只是导航提示，实际 DOM 为准）。自动打开登录后页面、按可见设置启用开发者模式、添加 OAuth 连接，填入准确地址，在授权页使用短时配对码。仅登录、验证码或页面明确要求本人完成的授权交用户；不重复询问自动/手动、固定/临时或 Project 选择。真正完成后才 `prefs set --developer-mode`，并核实对应连接可在普通 Chat 中选用。

不对其他连接执行删除、重新绑定或授权。更新连接要先核对准确名称、旧地址与工作区；无法唯一识别就停止该修改，记录缺口。页面要求且属于当前用户已授权连接工作的可自动点击；平台阻止代操作的步骤交本人完成，不回避限制。

临时地址改变时按当前页面能力恢复。能编辑服务器 URL 就更新同一连接；当前页面只有插件管理且 URL 只读时，核实名称、应用 ID 和旧 URL 后先卸载这个过期连接，再按新 URL 建立同工作区替代连接并重新配对，保存新的管理入口。卸载后的旧云端定义不能当成健康连接，也不因同名而误选。使用可恢复的卸载，不永久删除云端定义；不上传猜测格式的插件配置，不修改其他工作区连接。页面授权范围或平台审批超出已有明确授权时，只暂停此连接步骤，说明所需范围并交用户完成。

## 具体咨询

独立用户明确咨询请求可执行；流程内触发遵守主技能网页顾问，不扩大岗位职责。取得共享锁，复用当前任务/角色对话或新建普通 Chat；有全项目指挥指令的 Project 时新建不继承其指令的普通 Chat。独立审查使用独立对话。旧上游 session 的 Project 数据不是必备条件；当前顾问 URL 和角色写入凉笙任务记录，session 仅 `get` 只读，不修改原 URL、Project 绑定或上游检查点。

每次发送问题前，在当前普通 Chat 选择明确的 P11 连接，通过该连接调用 `workspace_info` 核对其连接身份、工作区名称/目录与本次批准目标，再 `read_file` 读取本次授权的任务材料并确认路径、版本后提问。工具名包含 `codex_with_chatgpt` 不能证明连接身份或工作区相符。原生 Codex MCP 若指向不同工作区，或无法核明它与当前 P11 连接及获批工作区的对应关系，不得代替网页读取；应暂停依赖网页的部分并报告，保留其它连接和可独立推进的工作。未实际核实前不能沿用旧验证或声称文件可读；网页可见结果不符就暂停并交维护，外部材料若连接读不到，精简附上必要说明并明确缺口。

```text
你是凉笙当前窗口的网页顾问。角色：{角色/独立任务}；任务版本：{版本}。
准确连接：{连接名}；工作区：{绝对目录/名称}。
先通过该连接调用 workspace_info，读取 {相对路径及必要行范围}，确认目录与输入版本；不符就停止。
本次目标与验收：{已确认内容}；允许范围：{模块/限制}。
问题：{一个具体疑问}；已尝试与证据：{必要事实}。
需要：{局部方案/代码及位置/验证方法}。
只在当前问题范围给建议，不派员工、不改需求/模型/预算/依赖/发布决定。
本地窗口负责核对、应用与测试；你的完成声明不代表本地测试或验收通过。
```

页面仍在生成时适当间隔读 DOM；不重复提交。超时先找回原页查看是否已发送/回复，再恢复。代码先核对当前公共接口、文件和批准范围，再应用与验证；带真实失败证据继续咨询，两轮无新证据/可验证进展则停止该咨询并记录下一步。未确认收到内容就不能宣称网页已建议、连接已可用或测试通过。

完成或暂停先在已有任务记录保存 URL、必要结果、验证及恢复位置，再释放自己的锁。P09 的审查结论须本地独立核实；网页顾问不重启项目流程。不保存完整聊天、配对码和授权凭据。
