# 凉笙 ChatGPT 适配

这是凉笙专用驱动，复用固定提交的 C2C 底层程序。需要连接、恢复、咨询或断开当前工作区时使用。普通任务不因技能可用就连接网页；流程内是否咨询遵守主技能[网页顾问](../liangsheng-workflow/references/网页顾问.md)，明确独立咨询请求可直接使用。

不读取、调用或重新安装原独立 `codex-with-chatgpt/SKILL.md`。底层不负责凉笙的任务推进、员工派工和验收；网页只回答当前具体问题，可给代码，本地窗口核对、应用并测试。不启动上游项目指挥循环，不要求 ChatGPT Project，不把 session 检查点作为凉笙状态源。

## 按请求操作

- **连接或恢复：**读[连接配置与恢复](references/连接配置与恢复.md)。实际需要时才检查；健康连接复用；首次或失效由凉笙专用维护窗口自动配置。默认 auto + quick，只把登录、验证码和必须本人完成的授权交用户。
- **咨询：**读[浏览器与咨询](references/浏览器与咨询.md)，取得共享锁后，在当前普通 Chat 选择并核对准确的 P11 连接身份及获批工作区，再通过该连接核实 `workspace_info` 与任务文件后提问。连接身份或工作区对应关系无法确认时，暂停网页依赖部分并报告，保留其它独立工作；原生 Codex MCP 不能因工具名相似而替代网页读取。独立审查对话与执行对话分开。
- **断开：**用户要求断开 ChatGPT 时，在共享锁内通过 wrapper 的 `unpair` 撤销当前工作区访问；明确要求“停止组件”时用 `stop` 停止服务。仅关网页标签不算撤销授权，不操作其他工作区。

本机入口和状态目录由 `scripts/c2c-adapter.mjs` 探测/配置。配置存插件之外，只含路径、版本与偏好；不打包凭据。新机器可自动安装[固定底层版本](references/upstream-lock.json)并重新配对；升级通过专门维护验证后采用。机器配置、浏览器登录和平台权限需按实际环境核实，不能假称完成。

同工作区维护和咨询共用主技能的 `scripts/advisor_lock.py`。取得锁、移交维护前释放自己的锁、完成或暂停时释放；不删除他人的锁。两轮无新证据或可验证进展就保存恢复位置并停止该咨询；只暂停依赖网页的部分，有依据的本地工作继续。

交付只记录用途、必要建议、采用情况、本地命令和结果；配对码/授权凭据不进入验收报告。真实联调、模型行为抽样、模拟测试分别标注，网页宣称成功不等于本地验收。


## Plan 中生成正式计划

正式计划生成前先询问“现在是否生成正式计划”，明确同意或直接要求生成才输出。已获生成许可且范围未变时沿用，不因等待真实 Plan 重问；重新讨论后的完整替代计划重新获准。生成计划须处于真实 Plan；修改文件、建窗和实施须有执行授权且真实退出 Plan。PRD 确认授权获批员工初始化，正式业务另等开工指令；各关口分别记录。


## 日常模型与岗位

日常模型以本轮批准配置为准：P00a 请求 gpt-6.1-sol / high，P00b 请求 gpt-6-luna / xhigh；其余岗位在讨论时确认。配置不可用或不匹配时报告，不静默降级。请求配置与可核实实际配置分开记录，后台不可见写未知。改版测试配置仅见维护验收资料。

## 项目岗位边界

P11 负责项目连接配置、恢复和断开；其他 P 岗位获批的顾问调用只覆盖当前任务咨询。需要维护时释放咨询锁并交 P11，不能因加载完整技能就执行配置、重配对、停止或断开操作。独立 CURRENT 与个人 MAINTENANCE 按用户本次明确请求操作。
