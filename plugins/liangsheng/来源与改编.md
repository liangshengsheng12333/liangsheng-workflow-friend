# 来源与改编

本包主驱动参考 [autopilot-skill](https://github.com/zkkk9555/autopilot-skill)，固定提交 `96161df4196d19f6d60911f3dc08a9a6ebbdd495`，原许可见 `autopilot-LICENSE`。25 个子技能来自 [mattpocock/skills](https://github.com/mattpocock/skills)，固定提交 `153fc1b93de6584562765cdce299324e1ff9e661`，原许可见 `mattpocock-skills-LICENSE`。两个来源均为 MIT。机器可读清单见 `上游来源.json`。

改编内容包括：中文触发描述与界面名、Codex 插件命名空间、基于文件的技能加载、计划生成、初始化执行、PRD 确认与正式开工四关口、P00–P11 独立聊天岗位、共享任务卡与报告、跨平台可复制任务包、整合后总审及隐私安全的个人使用日志。驱动的保留/调整对照在 `skills/liangsheng-workflow/references/动态驱动.md`。保留的各子技能方法已按任务授权和状态源作适配；脚本、模板和参考资料随所属技能收录。

v1.1.0 进一步改写 25 项发现描述和正文，区分独立请求与完整项目，明确相近意图分工；加入共用代码简洁约定并接入规划、提示词、实现、测试和既有总审。原机器名称、中文名和许可保持不变。自然路由依托 Codex 模型，不额外提供后台调度器。

v1.2.0 精简重复维护的授权和记录说明，拆分角色模板以便按需读取；简单提示词由 P02 填获批模板、P01 核对，复杂提示词由 P04 独立撰写。调整上游子技能中过于固定的脚本、课程、并行代理、复现、远端事项和 HTML 产物要求；补齐任务内部自主权、两轮无进展转交及非代码交付的适用条件。原有机器名称、授权关口和许可保持不变。

v1.3.0 增加模式一讨论确认入口与模式二完整项目入口，明确入口优先级；统一实际 Skill 使用反馈、下一步指引和当前轮次短通知，保留外部手动转交。新项目按任务集中记录并标实际平台，审查通过后按预先确认范围清理冗余过程记录，保留必要证据与去重编号；不迁改历史项目。

本包不运行上游安装脚本，不覆盖用户已有同名独立技能。第三方名称仅用于说明来源，不代表上游作者参与或认可此改编版。


## v1.5.0

新增来自 Codex with ChatGPT 的凉笙适配子技能，固定来源见上游来源.json及 LICENSE-codex-with-chatgpt。保留底层只读连接，替换配置、浏览器和顾问编排；运行时不加载上游技能，不执行原版指挥循环。日常使用固定已验证提交，升级经维护测试后采用。原25个子技能方法和辅助资源仍保留，构建共27个技能。


## v2.0

公共模式一精简初始化、模式二完整初始化、模式三当前窗口旧项目接续。P00 编写初版 PRD 并初始化真实员工，P03 维护后续需求，P11 处理连接，P01 获用户开工授权后驱动。子代理不替代员工窗口；实际技能读取、动作和验证构成调用证据。对外 v2.0，机器版本 2.0.0，共 27 个技能。


## v2.1

机器版本 2.1.0，个人候选版。P00 拆成 P00a（gpt-6.1-sol / high，PRD 与规划）和 P00b（gpt-6-luna / xhigh，批准后的固定初始化）。讨论先核对完整员工名单，模式二逐岗确认用途与配置；模式三合入统一恢复，保留旧口令兼容。项目进度采用极简恢复索引，P01 单批派发结束，由 P02 按依赖及异常事件唤起。

本轮纠正此前部分子技能整段重写、按整行过滤而丢失方法的问题。25 个方法正文与 Markdown 参考从上述固定提交重新生成，仅作可列举的命名空间、工具加载、操作归属及输出语言替换；各项正文 SHA256、行数和替换规则见 `方法适配清单.json`。凉笙前置约定限制操作授权，分析方法、参考模板、词汇表即时记录、原型证据、研究文件、逐轮拷问及代码审查双轴继续保留。代码任务默认按两份模板自查；批准临时代理才做隔离双轴检查，P09 最终独立总审另行执行。

文档拷问实际组合 grilling 与 domain-modeling。主驱动按岗位清单过滤所有推荐和嵌套调用，读取正文、核对产物并在事件出现时重判下一步。`check_skill.py` 是可复核的路由检查，不能代替模型遵循规则，也不构成平台权限隔离。未引入后台常驻调度器；自动推进依赖平台真实建窗、消息权限和本次批准范围。

本包为朋友版 v2.1 候选交付，排除个人模式零入口及个人内部维护档案。候选包本身尚未完成朋友设备安装和真实工作流验收；个人版测试记录不代表朋友版通过。
